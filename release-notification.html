Minecraft 1.12.2 Forge & Cleanroom v1.0.0 Release Zero GC Stutter

CIT Reforged v1.0.0

The optimized, standalone Custom Item Textures engine for Minecraft 1.12.2. Full OptiFine & MCPatcher CIT resource pack support without OptiFine installed.

🚀 Why this release matters: OptiFine causes frequent incompatibilities and memory crashes in modern 1.12.2 modpacks running performance mods like CensoredASM, VintageFix, or CleanroomMC. CIT Reforged solves this by loading all custom weapons, tools, armors, and items standalone with zero rendering allocations and complete OptiFine CIT feature parity.

⚡ Key Upgrades Over Original CIT-Recrafted

🏎️ Zero-Allocation Rendering Performance

CIT-Recrafted allocated a new cache key and deep-copied item NBT tags on every single frame for every rendered item. CIT Reforged introduces recyclable ThreadLocal lookup keys with precomputed hashes and an LRU model cache, eliminating GC stutters completely.

🏹 Dynamic Bow & Fishing Rod Models Visuals

Full support for OptiFine dynamic animations! Custom bows now correctly transition through pulling stages (pulling_0, pulling_1, pulling_2), and fishing rods switch seamlessly when cast or uncast.

📖 Enchanted Books Support Bug Fix

Enchanted books store their enchantments under StoredEnchantments rather than standard ench tags. CIT Reforged handles both tags natively so enchantment-based book textures render properly.

✨ Emissives & Animation Metadata Compatibility

Proper proxying and registration of OptiFine emissive _e.png textures and custom .mcmeta animation files. CIT packs with glowing runes and pulsing animations now work out-of-the-box.

📁 Universal Root-Level ZIP Discovery Packs

Resource packs that bundle CIT folders directly at the root level of the ZIP file (such as legacy MCPatcher packs) are now detected and loaded without requiring manual repackaging.

🎯 3D Perspective Preservation Rendering

Integrated PerspectiveModelWrapper ensures custom models adhere to proper camera transformations across First-Person, Third-Person, GUI, Ground, and Fixed item perspectives.
